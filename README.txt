ONE SMALL ACTION — Website
==========================
Open index.html in a modern browser.

Brand:
One Small Action. A Better You.

Features:
- Responsive sleek landing page
- Daily workout, study and reflection actions
- Add custom actions
- Complete/reopen actions
- 30-minute focus timer
- Progress tracking
- Browser-local saving

For real cross-device push notifications, accounts, cloud sync, and scheduled reminders,
the next version should add a backend and notification service.
